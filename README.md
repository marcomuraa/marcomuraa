## Selected work

- **[firma-digitale-demo](https://github.com/marcomuraa/firma-digitale-demo)**: a real PAdES digital signature taken apart byte by byte, in the browser, with no network access. The signature is genuine and verifies with OpenSSL and poppler. It also shows why a document that renders correctly is not a document that is verified.
- **[dsh-neutered](https://github.com/marcomuraa/dsh-neutered)**: a macOS fork of a coding agent that talks only to a local model on loopback. Remote integrations are removed, a network guard and a Seatbelt sandbox restrict what it can reach, and the README states the limits of those protections.
- **Case study (private repo, no code shared): B2B SaaS for out-of-home advertising operators.** Designed, built, deployed and sold solo, and delivered to a paying client. React and TypeScript, PostgreSQL with the domain logic in stored procedures, row-level security, mandatory 2FA, EU hosting, encrypted data, automated backups, GDPR-aware design. Inventory availability, contracts with expiry alerts, payment schedules, automatic quote and contract PDFs. It is no longer running.
